# S1 实施与验证记录

2026-10-29，依据 PRD v1.8，阶段进行中。用户已提供 Chrome 156、1440×731 CSS视口及其他环境确认，S0已通过；S1仍待本地样音与规格/原型审阅，不宣称门槛通过。

## 已实现

- 开发原型：启动原有本地服务后打开 `http://127.0.0.1:8765/dev/`。野餐与整理并排，均可切换故事、对话、游戏、词卡；正式首页没有新增整理入口。
- 野餐四幕、四轮三回应、四词；整理两幕、两轮双回应、三词与两个收纳区。数量独立，来自各自 JSON 内容包。
- 复用手绘样式与角色/食物资源，新增球和汽车手绘素材；小熊玩偶复用现有手绘熊形象。
- 对话卡只预选与试听，“就这样回答”才提交内存操作。示范只选中，不提交；后续换选切回儿童选择来源。提交后主动听接话、主动下一轮，不自动进入其他模块。
- 野餐完整听目标词后才允许确认，整理先选物品再选收纳区。尝试与确认快照只存在本页内存。
- 开发演练可模拟一次保存失败；失败时阻断换选和跳题，同操作ID重试；退出始终可用。旧保存回调不能推进新模块。
- 故事可逐短片段主动播放/暂停，词卡按实际词量分页；这些页面仅演练显示与声音，不记录完整幕或词音参与。
- 原型没有调用 `/api/event` 或 `/api/tick`，不会写家庭库，不冒充真实额度、贴纸、PIN或恢复实现。播放器现优先使用本地文件，缺失时明确标记开发语音回退，不代表离线交付。

## 机器契约与执行方式

`static/dev/model.js` 提供内容校验和独立交互状态模型，浏览器与Node检查共用。`build-samples.cjs` 生成两份草稿JSON，`draw-assets.cjs` 生成共用小插画；改内容源后重新生成。

```bat
cd /d D:\py_space\momoplanet
node validate-content.cjs
node check-prototype.cjs
node check.cjs
```

严格发布检查：`node validate-content.cjs --release`。当前应返回非零：两包均为草稿，正式音频缺失且来源/权限/审阅未完成。普通开发校验将待交音频列为警告，图像缺失、结构或引用错误仍失败。没有通过发布检查的样例不进入正式首页。

检查覆盖重复ID、空模块、引用、路径越界/外链、未知玩法/模板、热点越界、回应词数、候选数量、音频文本一致性，以及缺音频和草稿的发布阻断。真实字音、音量和视觉不能由此判断。

## 声音清单与分项估算

草稿音频逐条写入JSON资产表，含文本、语言、角色、本地路径、来源、权限和审阅字段。当前野餐40项、整理17项音频全部待交；每条缺文件和未审阅会各产生一项提示，因此警告条数不同于音频数。S1 先完成野餐一幕、一轮对话、一题和词卡的端到端样音，而非等待全部制作。

以下为单人投入的初步区间（人日），用于拆分工作，不是承诺日期；实机问题和资源审阅可能改变区间：

| 工作 | 预估投入 | 依赖 |
| --- | --- | --- |
| S1余项：原型实机核对、规格补齐、接口定稿 | 1–2 | 目标设备、声音样例 |
| S2：内容迁移、四模块拆分、引导、完整帮助和布局 | 4–7 | S1定稿 |
| S3：事务、迁移、单段/每日账本、租约、恢复与失败队列、PIN服务 | 6–10 | 内容与事件契约稳定，隔离迁移副本 |
| S4：家长设置、导出全清、声音接入 | 3–5 | S3，必要声音已交付 |
| S5：故障/离线/多页/设备矩阵与问题修复 | 2–4 | S2–S4，家庭自愿观察单列，不承诺日程 |
| 声音：端到端样音制作及审阅 | 1–2 | 确认可使用的配音来源、角色、语速 |
| 声音：正式清单批量制作、文本对齐及复验 | 2–4 | 样音审阅通过；不包含等待外部授权的时间 |

已提供10项端到端样音的SAPI生成脚本与WAV/文本/哈希校验；本轮生成被工具权限拒绝，未产生有效样音。新增播放器与WAV校验7项检查通过，阶段门槛检查增加至13项，详见 [样音制作与验收](S1_AUDIO.md)。样音、来源权限核查、人工审阅与浏览器视觉声音核验仍未完成；S1保持进行中，不推进S2。

# S1 交互与数据契约草案

2026-10-29，PRD v1.8。此文为接口设计，实施进度见 [S1交付记录](S1_DELIVERY.md)。S0已通过；双情景原型、内容包/校验器、分项估算和 [页面流程规格](S1_FLOW_SPEC.md) 已产出。端到端本地样音、实际声音与原型审阅仍未通过，不据此标记S1门槛通过。

## 页面和操作状态

首次进入家长声音检查及PIN设置，完成后到当前情景首页；后续启动只展示首页，不自动播放或恢复。首页四模块分别带有适用的“继续上次”和“从头再玩”，不新增第五个同级入口。家长入口次要展示；仅一个发布情景不展示切换器。

模块内部遵循：就绪 → 播放 / 预选 → 明确确认 → 保存中 → 反馈 / 下一段。播放与保存为独立状态，不能因声音结束推断保存完成。退出和切换在所有状态可用；立即终止声音和旧页面回调，再完成已确认操作和时间结算。失败不能阻止离开。

| 状态 | 主操作 | 对记录的影响 | 恢复 |
| --- | --- | --- | --- |
| 就绪 | 听、帮助、跳过、切换、结束 | 打开和跳过不算有效参与 | 主动开始 |
| 播放中 | 暂停、替换重听、切换、结束 | 完整片段才确认播放完成 | 中断短片段从头播放 |
| 预选 | 换选、试听、就这样回答 | 试听不写参与事件、不发贴纸 | 保留对话预选，仍需确认 |
| 保存中 | 禁用重复确认；退出可用 | 沿用同一操作ID | 先核对保存结果 |
| 保存失败 | 请大人帮一下、重试、离开 | 保留待确认项，阻断新活动 | 同ID重试，成功后主动继续 |
| 暂停 | 继续、跳过、切换、结束 | 前台可操作暂停计时 | 不重复已提交回应 |
| 模块完成 | 再玩一次、其他玩法、结束 | 不自动下一模块 | 重玩不重置额度 |
| 到点 | 静态告别、首页、家长入口 | 不提交未确认预选，已确认操作继续保存 | 每日不加额，单段重建须PIN |

固定顶部退出、稳定播放区，所有儿童目标至少64×64px、间距12px。对话历史折叠，避免挤出当前轮。复用手绘角色、卡片、画纸及焦点样式；技术错误仅在家长详情展示。

## 两情景的交互边界

| 模块 | 野餐（正式候选） | 玩具整理（内部草稿） |
| --- | --- | --- |
| 故事 | 四幕，各有独立片段和可点食物 | 两幕，不同构图，ball/car/teddy |
| 对话 | 四轮三回应，替小兔预选试听，再点“就这样回答” | 两轮，可不同回应数；同一确认流程 |
| 游戏 | 听完目标词才可选食物；有效选择提交尝试 | 先选玩具，再点收纳区提交；不依赖词音完成、不拖拽 |
| 单词 | 实际四词，每页最多四张 | 实际三词，共用分页组件 |

对话示范仅预选示例并标记 `source=demo`，仍须确认；换选清除不适用的示例选择标记。游戏“玩法解释”“再听一次”不高亮答案；只有“Momo示范”可高亮，并在本题后续尝试持续带示范标记。野餐本题的候选顺序在题目创建时确定，重试不重排。

## 内容包约定

使用只含数据的 JSON，不接受脚本、HTML、事件处理器或任意模板。资源路径限制在项目静态目录，禁止绝对路径、上级跳转及外部URL。渲染文字使用 `textContent`，资源通过受限ID映射；不拼接内容到inline事件。

- 包：`schemaVersion`、`sceneId`、`contentVersion`、`status`（draft/released）、`compatibleFrom`、`title`、`stickerId`、`assets`、`words`、`modules`。
- 全局词汇：ID表示语言与词义，如 `en.apple.fruit`。情景引用另有图像、词音与目标标记，同拼写不同词义不能复用ID。
- 故事：每幕稳定 `id`、`templateId`、1–2角色、一个主物品、最多两个热点与归一化坐标、英语短片段、中文释义。每片段不超过15词。
- 对话：每轮稳定 `id`、问题片段、2–3个回应。回应含稳定ID、图像、至多8词文本、声音及接话片段；不靠选项下标识别。
- 游戏：玩法ID、独立题目数组。野餐为 `listen-pack`，每题2–4候选；整理为 `select-place`，定义物品与收纳目标映射。
- 单词：目标词引用数组，独立于故事、对话、游戏长度；客户端每页最多4卡。
- 资源：每个声音有ID、文本、语言、角色、本地文件路径、来源及使用权限、审阅状态；插画复用手绘资源。
- 发布清单只列已发布情景。草稿只能通过明确开发入口打开，不得在正式首页出现。

校验器同时报告结构、重复ID、无效词/资源/选项引用、空模块、未知玩法或模板、越界坐标、缺资源及词数超限。草稿可以保存缺口，但缺口不代表可运行或可发布；发布校验失败须阻断正式入口。

## 身份、持久化和服务边界

存储拆为：体验（experience）、单段额度（allowance）、进度（progress）、事件（event）、每日及片段账本（ledger）、贴纸（sticker）、家长设置/授权。不能以体验结束来清空单段额度。

事件保存：`operationId`、`experienceId`、`sceneId`、`contentVersion`、`moduleId`、`practiceId`、`stepId`、类型、词汇ID、发生时文本与选项快照、帮助来源。服务端生成保存日期/时间，客户端自报时间仅辅助故障说明。旧事件保留原始归属，缺字段显示未知。

进度键为家庭×情景×模块：稳定步骤ID、片段ID、已完成片段、已确认回应与待播片段、游戏候选排列/尝试数/帮助/完成状态。未确认对话预选可存为非业务状态。兼容版本和步骤ID都有效才恢复；不兼容仅重置该模块位置，历史和额度不变。

操作先生成ID并写本地待确认队列，再提交；数据库同一事务完成操作去重、事件、对应进度、贴纸更新。丢响应重试同ID及同内容，ID冲突而内容不同必须拒绝。新主动重听/重玩用新ID，重试不生成新ID。页面离开使UI代次失效，不撤销已经确认的保存。

拟定服务分组（S3实现后才取代旧接口）：

| 分组 | 职责 |
| --- | --- |
| 状态 | 返回服务端余额、设置、真实获贴状态和情景×模块进度 |
| 活跃页 | 获取、续租、释放单活跃页；失联超过10秒可接管，旧token写入被拒 |
| 业务操作 | 同ID去重提交、事务内保存事件与进度；操作结果可核对 |
| 计时片段 | 同片段ID结算一次；服务端返回确认余额，不用客户端自加值作为权威 |
| 家长授权 | 带盐PIN校验、一次性恢复码、下调设置、新单段授权、导出和全清 |

正常退出先停止声音，结算末段与结束事件均确认后才显示“已保存”；保存失败显示离开选项并保留队列。后台尽力结算，重启先核对未确认项。日期倒退阻断、午夜切片、多页失效由服务端裁决；不能用客户端 `sessionStorage` 代替持久额度。

PIN使用标准库带盐密码派生并常量时间比较，不保存明文；恢复码另存派生校验材料，成功使用后轮换。导出排除这些秘密材料。迁移前备份，在临时副本验证，保留旧red与野餐归属。

## 声音交付和剩余门槛

本次目录核查：`static/audio/` 没有音频文件，当前代码实际依赖系统语音回退，正式离线能力未交付。S1 必须补野餐一幕、一轮对话、一题与词卡的本地端到端样音，记录来源、权限、角色、文本、语速和审阅结果；不以系统语音或静音占位文件替代正式资源。

已交付两情景内存原型、机器校验与样例、初步规格映射和开发/素材分项估算。剩余为端到端样音及审阅、完整逐AC规格演练和实机核验。只有这些完成且S0门槛通过，才将S1标记完成；当前实现不声称具备可靠恢复、PIN或离线播放。

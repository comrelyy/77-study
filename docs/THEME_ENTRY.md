# 主题入口（2026-10-31）

- `/`：独立主题选择页，不初始化学习活动、家庭记录或计时。
- `/?scene=picnic`：野餐四玩法首页。
- `/?scene=tidy`：整理玩具四玩法首页，使用本机持久记录。
- `/?dev=tidy`：保留隔离内存演示，不写入家庭记录。

选择页与主题首页分开；“切换主题”和页头品牌链接均在停止声音、保存进度、确认待提交操作并释放活动后返回选择页。保存失败时显示恢复提示，暂不跳转。各主题首页底部的退出操作仍放在“给家长的说明”下面。

整理主题为 0.3.0，包含三幕故事、六轮对话、三件玩具的收纳游戏及词卡，39 条本地 WAV 已生成。`tidy-content.cjs` 为故事补全来源，`build-content.cjs` 会保留上一版本归档。运行 `make-s4-audio.ps1 -SceneId tidy` 可维护声音及独立来源清单。音频文件有效性不代表听感或使用权限审阅通过；内容仍为开发预览，未改为正式发布。

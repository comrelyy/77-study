# S1 本地样音制作与验收

2026-10-29更新：10项S1样音技术检查已通过，用户确认“完成，直接进入S2阶段的开发”。确认来源及声音/内容指纹登记在 `reports/s1-user-confirmed.json`，据此进入S2；没有伪造结构化审阅表或助手听感结论。以下生成限制为此前工具执行记录，不能继续误报用户本机未生成样音。正式分发来源审阅和全部本地资源仍属S4交付。

## 当前实现与限制

开发原型已接入本地文件优先的播放器：完整 `ended` 才算播放成功；暂停、切换、后台与离开使旧回调失效。缺文件仅在开发原型明确允许时回退到设备语音，并显示来源。正式离线或样音验收不能使用回退结果。

样音范围：野餐第一幕2段、第一轮问题1段、三回应与三接话6段、apple词音1段，共10个本地WAV；apple词音同时用于游戏首题与词卡。来源、角色、文本、速度、音量与文件哈希写入清单。

工具环境实测：`.NET System.Speech.GetInstalledVoices()` 抛出异常；SAPI可枚举 Microsoft Zira 英语和 Huihui 中文，但 `Speak` 写文件返回 `E_ACCESSDENIED`。失败产生的46字节无音频数据文件已清理，未作为素材保留。此为工具访问限制，未推断用户本机声音不可用。

## 在本机生成内部候选样音

脚本由项目提供，不需要家长自行配音，也不安装依赖。CMD运行：

```bat
cd /d D:\py_space\momoplanet
powershell -NoProfile -ExecutionPolicy Bypass -File .\make-s1-audio.ps1
node check-s1-audio.cjs
```

参数只对该PowerShell进程生效，不修改系统执行策略。脚本只使用已安装的指定英语声音，在项目 `static/audio/picnic/` 创建文件；不覆盖现有素材，不修改家庭库。生成失败会清理本次未完成的临时文件。若指定声音不存在则报错，不擅自换成中文声音。

输出清单：`static/audio/s1-sample-manifest.json`。其中 `reviewed=false`、`rightsStatus=pending review` 保持真实；合成成功不代表已听感审阅或已获对外分发许可。当前语音候选用于内部试音，来源/使用权限核查通过后才能作为正式资源。

技术检查验证10项存在、WAV/PCM格式、时长、非空非静音占位数据、文本/角色/语言与清单及SHA256一致。输出到 `reports/s1-audio-technical.json`。不通过就修复，不生成假的通过记录。

## 后续审阅

技术检查通过后，在 `/dev/` 的野餐第一幕、第一轮、游戏首题与apple词卡试听，确认状态文字显示“本地文件”，不接受“开发回退语音”。核对发音、含义、角色差异、语速、音量、分片边界及暂停/重听。结合目标视口核验原型操作可见与手绘一致性，并核对流程与契约。

已实现审阅页面 `http://127.0.0.1:8765/dev/review.html`。生成样音后先运行 `node check.cjs` 更新源码指纹，再打开审阅页。该页逐项核对WAV和清单哈希，显示原文与角色；未完整播放全部10项本地文件时不能勾选听感审阅。声音来源/使用范围由项目内容负责人核查，不自动勾选，不要求家长承担专业审校。

审阅记录包含审阅者、时间、内容版本、源码/样音指纹、完整试听ID和问题处理结论。文件存在或播放完成不代表主观听感或使用权限通过；须如实勾选。导出可以包含未完成状态，阶段校验会拒绝不完整记录。下载到默认目录后运行：

```bat
node stage-gates.cjs --stage S1 --review "%USERPROFILE%\Downloads\momoplanet-s1-review.json"
```

脚本导入记录到 `reports/s1-review.json` 并核对当前源码与实际样音。改代码、契约、样音或来源清单后，旧指纹不匹配会阻断，需要重新审阅受影响内容；不能提前写true或只凭旧报告通过。

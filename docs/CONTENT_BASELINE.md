## 当前交付与限制

- 内容源为 `launch-content.cjs`；`build-content.cjs` 生成八个 JSON 内容包，并先归档现有包。现有野餐更新为 0.3.0，整理更新为 0.4.0；六个新主题为 0.1.0。旧声音、归档和家庭历史不删除；不兼容版本不恢复旧位置。
- `draw-content-assets.cjs` 生成物品和逐幕场景 SVG；`draw-assets.cjs` 重建原有角色后也重建这些场景。小熊玩偶不再引用 Momo 角色图。
- 逐幕分镜已补上具体的物品位置和过程：袜子在椅子下、食物分给两位朋友、玩具从地面移到箱内/架上、公园球滚远、购物袋装入水果。离线渲染检查图见 `reports/content-art-contact-sheet.png`；这是插画检查，不是 Chrome 全页面验收。
- 游戏仍只有听音选图、选物品再选位置两种机制。主题任务与摆放区不同，不代表已经有八种不同玩法。
- `make-s4-audio.ps1 -SceneId <id>` 生成每主题 Windows SAPI 声音。357 条均为本地 WAV；技术检查包含结构、非静音以及生成清单文本、声音名称与文件哈希一致。
- 生成清单不能证明音频实际说出了正确的文本，不能证明发音、年龄适配、可理解性或分发权限。所有声音的人工审阅保持待办。
- 八包均为 draft，开发不限时；`releasedScenes` 为空。`requiredReleaseScenes` 声明八主题首发范围，只有单个主题获批不能再被误报为完整首发就绪。
- 内容和素材质量仍需逐条审阅，主题间难度、重复体验的价值、实际可用时长和可持续使用程度需要体验验证。不给整体完成度百分比。

## 检查与审阅

```powershell
node content-audit.cjs
node check-launch-content.mjs
node check-themes.mjs
node check.cjs
node s5-release.cjs
```

`reports/content-audit.json` 汇总八主题实际文件、词汇复现、声音来源匹配和待审阅数；只报告技术检查，不自动批准内容。统一检查包含全部八包及其在用图片、声音、生成来源清单的源码/文件哈希，修改任一在用资源将使旧发布检查证据失效。

运行中服务加载内容时，可识别启动后新增的合法主题包；路径和版本经过约束，JSON 损坏的新增包返回无效内容。对应隔离测试验证了启动后增加主题、保存及读取进度。已经运行旧版 Python 代码的服务仍需重启一次才能使用此修复；不要清空家庭数据。

本轮最终验证：统一检查 54/54、Python 隔离测试 38/38 通过，无跳过；357/357 WAV 技术有效且生成清单匹配。37 份逐幕 SVG 通过 XML 解析并离线渲染，已查看总览并修正物品漂浮/遮脸及收纳位置；隔离服务的审阅页和 423 个不同在用资源 HTTP 请求均成功。一次完整测试曾出现 Windows 本机连接中止（10053），失败报告保留在 `reports/content-backend-transient-network-failure.json`；HTTP 专项及完整统一检查复验通过，没有跳过该测试或更改失败判定。以上不替代真实浏览器布局、听感和家庭观察。

启动服务后访问 `/dev/content-review.html`，逐幕对照中文、英文和插画，展开每轮问题、所有回应和接话单独试听。多个播放器互斥，页面进入后台暂停声音；不调用家庭业务接口。笔记下载只保存发现、时间和内容版本，不等于发布审批。

浏览器故障、日期及清除实验仍只用隔离服务：

```powershell
python scripts/preview-isolated.py
```

该服务监听 `127.0.0.1:8766`，数据库在临时目录。正式本地体验仍是 `127.0.0.1:8765`，使用家庭库；不要把隔离验收记录当作家庭实际使用记录。

## 发布门槛

1. 八主题均完成四模块、必要图音素材与逐项内容审校；内容发布状态和分发来源有依据。
2. 自动检查通过；全部合法词汇复现路径正常，不依赖系统语音回退补齐缺失文件。
3. 当前版本 Chrome 桌面及窄窗布局、播放、暂停、后台、退出、恢复、多页与断外网实测有记录。
4. 正式限时模式单独复验；正式清单与八主题范围一致，无阻断问题。
5. 自愿家庭观察如实记录，评估情景是否自然、孩子能否理解、是否愿意重玩。不虚报反馈或学习效果。

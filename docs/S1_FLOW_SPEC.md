# S1 页面流程与状态规格

2026-10-29，PRD v1.8，Chrome为目标浏览器。本规格补齐设计演练，不代表真实PIN、账本或恢复已经实现。

## 页面导航与状态

| 页面 | 进入条件与操作 | 声音、记录及离开 |
| --- | --- | --- |
| 首次声音检查 | 家长主动播放本地样音并确认；失败可重试或退出，不因点播放按钮就判成功 | 不计儿童时间，不发参与贴纸；未确认不进入儿童活动 |
| 首次PIN | 声音确认后设置4位PIN并二次输入，展示一次性恢复码供保存 | 仅完成设置才进首页；不明文保存，不记录到体验事件 |
| 情景首页 | 四模块独立入口；有位置的模块附继续/从头再玩；单正式情景无选择器 | 无自动声音，无儿童计时；最近进度不成为第五同级入口 |
| 模块首次示范 | 可跳过、可重看；解释主要操作，不自动提交 | 计儿童前台时间；示范与真实尝试来源分开 |
| 故事 | 幕和片段独立ID，主动播放/暂停/重听/跳过；有折叠释义 | 中断片段重播，完整英语幕才记录；词音单记，中文不算目标完成 |
| 对话 | 替小兔预选卡片并试听；独立“就这样回答”才提交；可换选/拒绝 | 试听不参与、不获贴；已确认回应保存后播放回应与接话，后台/切换后主动继续待播片段 |
| 野餐游戏 | 创建题目时固定候选排列，目标词完整听完后点食物即提交；未匹配可重听/求助/跳过 | 不额外增加确认按钮；过早点食物不记答案；示范不替孩子提交且本题持续标记 |
| 整理游戏 | 先预选物品，再点收纳区提交；可换物品，不拖拽，不设词音门槛 | 同一次点击收纳只提交一个操作，连续点击不多次完成 |
| 单词 | 当前情景实际词量，每页最多4张，随时结束 | 完整词音才记参与；无需点完，不展示掌握度 |
| 模块结束 | 再玩一次/其他玩法/结束，不预选下一模块 | 不自动跨模块；重玩新练习ID，不重置余额 |
| 儿童贴纸 | 每情景终身一张，服务端确认后展示；无领取任务 | 前台时间计额度；纯跳过不获贴，结束不挽留 |
| 记录和设置 | 次要家长入口；受保护操作需PIN授权；记录不推断偏好/能力 | 不计儿童额度；技术错误和详细数据在此展示 |
| 情景选择 | 多正式情景才显示分页卡片选择；草稿只在开发路径 | 切换保留模块位置并停止旧声音；额度共用 |

## 共同边界与故障演练

| 触发 | 预期处理 | 验证重点 |
| --- | --- | --- |
| 播放中暂停、重听、切换 | 取消旧声音与回调；重听从短片段开头 | 旧ended/请求不能推进新页面 |
| 回应卡预选/换选 | 显示描边、文字标记，可试听；不提交 | 事件和贴纸不变化；示范后换选记录真实来源 |
| 明确确认 | 生成操作ID及文本快照，写待确认项后提交，锁定重复确认 | 双击/丢响应仍只产生一次业务事实 |
| 保存失败或响应不确定 | 停声音、阻断新增；简单说明，请大人重试或离开 | 原ID原内容重试，不能生成新ID；成功后主动继续 |
| 保存中立即退出 | 先停声音和儿童操作，保留待确认项，继续已确认保存 | 不能因保存失败困住退出；未确认成功不写“已保存” |
| 后台与强关 | 后台停止声音，尽力结算并保存本地待确认队列 | 重启先核对未确认项，不能凭空续满；不保证任何故障绝对不丢失 |
| 额度首次跨30秒 | 一次静态或不冲突的轻量声音提醒，无数字倒计时 | 对白中不插播，重入不足30秒不重复播报 |
| 单段/每日到点 | 立即停声音与新增选择，静态告别；完成已确认保存 | 未确认预选不提交、不记错；单段重开需PIN，每日不得追加 |
| 设置下调 | 仅相对当前值下调，单段≤每日，立即重算 | 不删除已用时间；已用达限立即到点 |
| 多页 | 只允许一个儿童活动页；失联超过10秒才可接管 | 旧租约被拒，新页也不能续满余额 |
| 午夜、日期倒退 | 午夜分账但单段延续；倒退暂停，前进记录跳变 | 不根据新日期重置单段，不宣称防改时钟作弊 |
| 内容不兼容更新 | 提示家长，仅重置受影响模块位置 | 保留历史、贴纸及额度；兼容依赖稳定ID和显式声明 |
| 声音失败 | 可看图、重试或结束，不能将失败当听完 | 听音游戏不给有效答案许可，本地验收不接受系统语音回退 |

## 内容与服务接口的规格演练

1. 三词两幕两轮整理样例与四词四幕四轮野餐，共用模块和事件模型，证明各数组长度独立；第二玩法只增加适配器，不复制产品页面。
2. 任意内容字符串用textContent显示；选择按稳定ID关联，不把文本插入inline事件；资产路径仅限静态目录。草稿不是正式发布内容。
3. 参与事件、进度、体验、持续单段、每日账本分离；同词全局ID共享，场景图音和事件来源保留。
4. 退出体验不关闭单段额度；恢复键为家庭×情景×模块；重玩只建立新练习ID。
5. 业务保存与贴纸在同事务，计时片段按ID幂等；同ID不同内容拒绝；导出不含PIN或恢复码校验材料。
6. 正式发布需要四模块资源完整，内部草稿允许列出缺项，但无效引用、未知玩法、缺正式资源均阻断发布。

上述规则对应AC-02–AC-18及AC-25–AC-30的设计演练。模型自动检查仅覆盖已实现的部分，真实界面、声音审阅和S3服务行为分别验证，不能用此规格替代运行结果。

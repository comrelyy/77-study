## 故事调整

十二主题各六幕，共 72 幕。每幕由一段旁白和两位角色的实际交流组成：有愿望或任务、发现的小困难、朋友提出的办法、合作尝试与收尾。段落并非只有替换目标名词。

例如：

- 出门：袜子不见了→朋友一起找到→鞋子不舒服→交换再试→朋友的袖子也卡住→两人都准备好。
- 整理：地板不能滚球→一人拿球、一人扶箱盖→找到小汽车→小熊放不下，请人帮忙→再检查遗漏→只取一个球一起玩。
- 做点心：准备分享→番茄滚走→找勺子→检查是否每人都有一份→Fifi 搅得太快、Toto 扶碗→一起享用。
- 天气：想出门→看云并有不同想象→突然下雨→记起雨伞→承认没能出门的失落、一起讲故事→天气变化后重新商量。
- 种植：准备花盆→放种子→慢慢浇水→当天下午还看不到花→明确过了好多天才开花→商量轮流照顾。没有把开花描写为当天发生。

Momo、Lulu 继续作为熟悉伙伴；新故事也出现 Fifi、Toto。各幕图片使用实际出场的两位角色，英文台词标注说话者，本地声音按角色给出不同的相对语速。仍使用 Windows SAPI 的同一离线声音，不宣称真人分角色配音或听感已合格。

现有八主题故事全部重写，原有角色对话保留并与新情节核对；新增四主题各六轮对话。全库现有 74 轮对话、149 个回应选项。台词快照、预听不提交、明确确认后保存、可拒绝/跳过等规则保持。

## 四种玩法

| 玩法 | 操作 | 使用主题 |
| --- | --- | --- |
| 场景找物 `scene-find` | 先听英语，再在一张场景图中找物品；物品按场景位置分布，不再只排成词卡 | 出门、公园、乘车、天气 |
| 故事排序 `story-order` | 把三张动作卡放入顺序槽，可撤回最后一步、调整后明确确认；示范不自动提交 | 洗漱、早餐、做点心、种植、睡前 |
| 选择并放置 `select-place` | 先选玩具，再选实际收纳区 | 整理 |
| 听音收集 `listen-pack` | 完整听完目标词，再找图收集 | 野餐、商店 |

现有 32 项游戏任务，包含五个三步骤排序任务；不能与过去 31 道单次点选题按数量等价比较。

排序有明确的本次故事计划。早餐顺序并非宣称现实中唯一正确的用餐顺序；洗漱只排列搓肥皂→冲净泡泡→擦手，床和水滴不再被当作能拿去收纳的物件。

排序的部分选择、候选排列、尝试、示范和最终提交都可保存/恢复。完整顺序由后端校验，不能只相信前端发送的“成功”。找物必须先听完目标音；切题/恢复后需要重新听。错误尝试和重试按原有规则记录，丢响应重试不重复生成参与或贴纸。新内容版本不兼容旧步骤，保留历史与归档。

# 情景互动整合与故事播放修复 · 2026-11-03

用户反馈故事重听无声，并要求将对话与互动整合、选中回答后直接进入下一句。本轮改变的是当前产品交互；旧文档中的“先预听再点就这样回答”和对话/游戏两个独立入口不再适用于当前家庭预览。

## 当前行为

- 主题首页和模块导航保留“主题小故事、情景互动、单词汇总”三个入口。情景互动中按主题安排对话与小游戏，完成当前小任务后接着下一句，不要求回首页另开游戏。
- 点回答卡即提交这次回应，保存确认后播放小兔回应、Momo接话，再进入下一句或该轮对应的小任务。移除“就这样回答”按钮。忙碌时锁定卡片；快速双击只记录一次。
- “示范回答”只播放范例，不提交回答。声音中断时可继续该段；保存失败时保留待确认操作，同一编号重试，不自动替用户改选。
- 小游戏保留重听、示范、跳过、暂停与结束；排序支持撤回。游戏“继续”会接回对话，重复快速点击不跳过下一题。
- 进入或恢复页面仍不自动播放（2026-11-12 例外：课程中点击进入一页式「故事」会自动朗读，恢复不自动播，见 `docs/LESSON_LINE.md`）。主动回答后才自动接话和进入下一句；暂停、后台、退出和旧回调的保护保持。

十二主题的任务穿插点来自内容包的 `interaction.gameAfterDialogue`，按对话轮次单调排列。例如做点心在第五轮“点心差点洒了”之后接准备点心排序，再回到第六轮邀请分享。整理在放球、找汽车和安置玩偶的对话后对应收纳任务；公园在观察树、花、小鸟及玩球的对话后对应找物。

## 故事无声修复

已复现：旧“重听这一幕”只重置故事进度并重绘，没有调用播放器；因此点击后不会发出故事音频请求。声音失败时的状态也会被重绘清空，看不到原因。

现在“听英语故事”和“重听这一幕”共用实际播放入口，重听立即从本幕旁白开始，接着播放两位角色的台词。在点击的同步任务中触发 Audio.play，不先等待保存请求。中途重听会终止旧播放；旧回调不能重绘并停止新声音。暂停后重播中断的片段，声音失败显示重试提示，不写入完整听过记录。

本次检查了截图中做点心第一幕的旁白及两句角色台词，本地音频请求均返回200。播放器和实际按钮的回归验证覆盖十二主题；这是代码/资源验证，不宣称已听过用户电脑的扬声器输出。

## 保存和恢复

首页合并入口不改写历史：对话与游戏仍以原有 moduleId 各自保存。新增游戏流程结束标记 `finished`，排序和找物的进度保持原粒度；返回情景互动时可恢复未完成的小游戏。重玩整段互动会同时重置本次对话和游戏位置，不清除历史、贴纸或额度。

核心文件：`static/core/interaction-flow.mjs`、`static/core/app.mjs`、`static/modules/dialogue.mjs`、`static/modules/story.mjs`。`content-v2.cjs` 定义穿插点，`build-content.cjs` 生成内容；媒体资源和台词未因本轮入口合并重做。
